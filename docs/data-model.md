# 数据约定

## 单位

局部坐标 x 向东、y 向北、z 向上，长度为米；z 相对城市参考原点，不等同于任意地形上的离地高度。
显示层通过唯一坐标转换模块映射到 WGS84，算法禁止直接以经纬度差计算距离。
速度为米/秒；航向从北顺时针；气象风向表示来风方向；电量为 0～1；优先级越大越优先。

## 实体

| 实体 | 关键关系 |
| --- | --- |
| Aircraft | 当前状态快照；altitude 是 position.z 的派生字段 |
| Waypoint | 三维位置、起降点/普通航点/备降点类型、容量 |
| AirRoute | 有序航点序列，start/end 必须与序列端点相符 |
| Mission | 任务起终点、分配的飞行器及飞行计划 |
| Weather | 影响多边形、风速/风向、能见度和降水类型 |
| AirspaceRestriction | 影响多边形和高度带、是否激活 |
| Event | 类型、审计时间、仿真时间、输入参数和处理结果 |

API 输入与领域快照分开：派生利用率、轨迹累计值、内部处理结果由系统维护。
新增场景只提供初始条件；运行流量和统计指标由仿真计算。

## 持久化

MVP 使用 SQLite 存储实体 JSON、场景元数据和运行记录。可检索的 ID 是主键。
跨实体关联由应用服务在事务内校验；直接使用仓储的内部代码承担相同的领域校验责任。
PostgreSQL/PostGIS 适配时实现仓储契约，并补充数据库关联和空间索引。
