# 迭代验收记录

每阶段可独立启动后再进入下一阶段。当前十阶段工程实现和本地验收如下：

| 阶段 | 验收结果 |
| --- | --- |
| 1 基础框架 | SQLite/内存仓储、Pydantic 模型、CRUD、事务回滚、关联校验、启动脚本及 OpenAPI；仓储与 API 测试通过 |
| 2 三维环境 | 程序化建筑、连续几何碰撞、ENU/WGS84、分层有向航路、邻接自动生成；几何与航路测试通过 |
| 3 路径规划 | 五权重加权 A*、2D/3D、禁入区、容量和动态重规划；算法与 API 测试通过 |
| 4 仿真调度 | 固定步长、倍速、任务分配、实际轨迹/电量/延误、暂停恢复；运动与 SQLite 恢复测试通过 |
| 5 冲突处置 | 连续时空检测；速度、高度、改航、延迟候选及全机安全复检；边界与回归测试通过 |
| 6 动态事件 | 天气、临时空域、拥堵、故障备降的事件注入、重规划和留痕；集成测试通过 |
| 7 三维前端 | Vue/TypeScript/Cesium/ECharts 离线程序城市及控制台；类型检查、生产构建和浏览器渲染通过 |
| 8 实时同步 | WebSocket 首帧完整环境、后续约 200ms 全状态、环境变化重发；API/WS 测试通过 |
| 9 自动演示 | 生成 100 机完整演示与五个独立事件场景；拥堵、雷暴、临时管制、真实备降和冲突解脱均由仿真推进并生成报告；浏览器与无浏览器运行验证 |
| 10 综合验收 | 全量回归、100 机性能测量与页面交互检查；规划段约束缓存、仅在航段变化时重算占用和 Cesium 静态图形复用后，完整运行约 44.7 秒，见演示报告 |

初始仓库基线为 57 项测试。管制与雷暴区域内撤离、事件后的即时安全复检加入后，全量 222 项测试通过，存在 2 项上游 TestClient 依赖弃用警告，不影响运行。项目使用 uv.lock 与 Python 3.12 隔离环境。指标与仿真结果需按 docs/demo.md 的口径解释。
